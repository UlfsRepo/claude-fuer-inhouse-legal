# Wissensbasis

Zweistufiger Aufbau der Wissensbasis in SharePoint: drei flache Bibliotheken (Verträge, Templates/Muster, Stellungnahmen/Gutachten), schlankes CLM-migrationsfähiges Datenmodell (6–8 Metadatenfelder mit Auswahllisten), pro Kategorie genau ein verbindliches Dokument. Methodische Grundlage: Skill [wissensbibliothek](../../../legal-operations/skills/wissensbibliothek/).

Echte Unterlagen, Bibliotheksinhalte und interne Metadatenwerte bleiben lokal.
