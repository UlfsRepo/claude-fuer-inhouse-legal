Alle Workshop-Unterlagen liegen hier als Markdown vor. Die Dateien sind so geschrieben, dass sie direkt als Prompt-Grundlage in **ChatGPT Enterprise** dienen, um daraus PowerPoint-Slides und Arbeitsmaterialien im Corporate Design zu erzeugen.
